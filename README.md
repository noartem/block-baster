# Block Baster

A free, open-source, **ad-free** block puzzle game inspired by *Block Blast*.
Runs in any modern browser (installable as a PWA, works offline) and as an Android app you can sideload.

- 8×8 board, three pieces per round, drag & drop
- Clear full rows **and** columns; several lines at once and consecutive clears build combos
- Clear the whole board for a bonus
- Fair dealing: every new set of pieces can always be placed somehow, so you only lose through your own moves
- Your game and best score are saved automatically
- No ads, no tracking, no network access needed. All graphics and sounds are generated by code.

## Play

- **Web:** once GitHub Pages is enabled (see below), the game is at `https://noartem.github.io/block-baster/`.
- **Android:** download `block-baster.apk` from the [Releases](https://github.com/noartem/block-baster/releases) page
  (or from the *Android APK* artifact of any CI run), open it on your phone and allow installing from unknown sources.

## How to play

Drag a piece from the tray onto the board. When a row or column is completely filled it is cleared.

| Event | Points |
| --- | --- |
| Placing a piece | 1 per block |
| Clearing *n* lines at once | 10 · n · (n + 1) × combo |
| Combo | grows by 1 for every move that clears a line; resets after 3 moves without a clear |
| Clearing the whole board | +300 |

The game ends when none of the remaining pieces fits on the board.

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev          # local dev server
npm run typecheck    # TypeScript
npm test             # unit tests (Vitest)
npm run test:e2e     # browser tests (Playwright; run `npx playwright install chromium` once)
npm run build        # production build in dist/
npm run assets       # regenerate icons & splash screens from scripts/generate-assets.mjs
```

Useful URL parameters: `?seed=123` starts a reproducible game, `?reset` clears saved data.

### Project layout

```
src/game/      pure game logic: board, shapes, piece generator, scoring (fully unit tested)
src/render/    canvas renderer, layout, procedurally drawn block sprites
src/audio/     Web Audio sound effects synthesised at runtime
src/app.ts     input handling, animations, menus, persistence
android/       Capacitor Android project
tests/unit     Vitest tests          tests/e2e  Playwright tests
```

### Android APK

Building needs JDK 21 and the Android SDK (or just let CI do it):

```bash
npm run android:apk
# -> android/app/build/outputs/apk/release/app-release.apk
```

Every push runs the **CI** workflow, which tests the game and uploads the APK as an artifact.
Pushing a tag like `v1.0.0` also creates a GitHub Release with the APK attached.

**Signing.** Without extra setup, APKs are signed with the public key in `android/app/debug.keystore`,
so new builds install over older ones. For official releases, create your own private key and add it as
repository secrets. Once you do, builds use it automatically:

```bash
keytool -genkeypair -v -keystore release.jks -alias blockbaster -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # value for ANDROID_KEYSTORE_BASE64
```

Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Android refuses to update an app with an APK signed by a different key, so uninstall the community build first when you switch.

### Web hosting

The `Deploy web version` workflow publishes `dist/` to GitHub Pages on every push to `main`.
Enable it once under **Settings → Pages → Build and deployment → Source: GitHub Actions**.
The build uses relative paths, so `dist/` can also be uploaded to any static host.
